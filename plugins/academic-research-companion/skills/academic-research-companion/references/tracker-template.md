# Project Tracker Template

Create one tracker per research project. Fill what's known; leave the rest as placeholders. Update at the end of any session where state changed, then deliver it back to the user (Notion page if the connector is available and the user prefers it; otherwise a downloadable file the user re-uploads to resume).

When resuming from an uploaded tracker: read it fully, confirm the current phase and next actions with the user in one short summary, then continue — don't re-interview the user on things the tracker already answers.
